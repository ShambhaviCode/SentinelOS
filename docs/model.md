# Model

## Status

**Selected, not yet verified on the target laptop.** This file records the selection
rationale. Measured results belong in `npu-verification.md` and `benchmark-results.md`,
which are generated by scripts.

## Selected model

| | |
|---|---|
| Model | `acuvity/distilbert-base-uncased-prompt-injection-v0.1` |
| Source | https://huggingface.co/acuvity/distilbert-base-uncased-prompt-injection-v0.1 |

| License | Apache-2.0 as listed on the model card. **Re-check the card before submission.** |
| Language | English only (per the model card) |
| Input | 128 WordPiece tokens, static shape `[1, 128]` (QNN HTP needs static shapes) |
| Output | Two logits; SentinelOS reports the softmax probability of the injection class |

## Why this model

- **Small enough for interactive, on-device use.** DistilBERT-class models are a
  realistic target for an NPU and fast on CPU.
- **WordPiece tokenizer.** SentinelOS tokenizes in pure Python, so no native tokenizer
  wheel is needed on Windows ARM64. `tools/export_model.py` checks token-for-token parity
  with the Hugging Face tokenizer.
- **Permissive license.**
- **Qualcomm AI Hub was not assumed to offer a prompt-injection classifier.** If a suitable
  AI Hub model is found, it can replace this one through the same `labels.json` / `vocab.txt`
  / ONNX contract.

## Fallback candidates

Any BERT/DistilBERT sequence classifier with a WordPiece `vocab.txt` works with
`tools/export_model.py --model <id>`. Check each candidate's license before use. DeBERTa-based
detectors use a SentencePiece tokenizer and are **not** supported by the pure-Python tokenizer.

## Pipeline

1. `tools/export_model.py`: download, export to ONNX (opset 17, eager attention, static
   shape), write `vocab.txt` and `labels.json`, check tokenizer parity and ONNX-vs-PyTorch logits.
2. `tools/quantize_qnn.py`: QDQ quantization with ONNX Runtime's QNN helpers
   (`qnn_preprocess_model`, `get_qnn_qdq_config`; uint16 activations, uint8 weights),
   calibrated on the synthetic demo texts plus sample benign and malicious prompts. Reports the
   fp32-vs-QDQ probability difference and any label flips.
3. `tools/verify_npu.py`: evidence of NPU execution (see `npu-verification.md`).

## Known limitations

- The calibration set is small (about 20 texts). Check the reported label flips; if any
  occur, add more calibration text or try `--activation uint16` (default) vs `uint8`.
- The model's published metrics come from its authors and are not reproduced here.
  SentinelOS does not claim a detection rate.
- Inputs longer than 128 tokens are truncated. Long documents are scored on their first 128
  tokens only; the deterministic rules still scan the full text.
